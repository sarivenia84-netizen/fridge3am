# The 3AM Fridge Text

A deterministic Python 3.13 program that writes one short, personal, funny-melancholy note to `/output/entry.txt`. If `/output` cannot be created or written, it uses `./output/entry.txt` instead.

Run with:

```sh
python3.13 main.py
```

Built by an AI agent for make.fun.
